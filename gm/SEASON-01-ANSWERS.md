## What you need to make

- **Runner cards** (Dead Drop): any number, each with the QR + code. Hide them in cafés, campuses, on walls.
- **Glitched-obelisk posters** (Torn Poster): code hidden inside the noise.
- **Handoff card pairs**: half the code on each card. Hand them out so strangers have to meet.
- **Black keycards** (Keycard): three districts.
- **Instagram bio code**, **TikTok frame code**, **static post** with a code in the corners.
- **Loot**: holo sticker packs, partner discount codes, keycards with callsigns, metal pins, Founding Runner patches.

You can give each physical card its own code: make several with `#gm` and add every hash to the quest's `answers` list.
